# Documentación del proyecto

Documentación de entrega del **Proyecto 3: Sistema de Predicción de Viabilidad para la Instalación de un Centro de Procesamiento de Datos** (Máster de FP en IA y Big Data, Stucom).

Los documentos están en Markdown para versionarlos con el código. El documento único de entrega en Word se genera con:

```bash
python scripts/generar_docx.py
```

y queda en `docs/entrega/Proyecto3_Documentacion.docx`.
